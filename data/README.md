# Data inputs

The end-to-end notebook reads repository-relative files only.

## Core ML inputs

- `raw/daily_hydroclimate_groundwater.zip`
- `raw/sinkholes.csv`

## Figure 3 map inputs

- `map/wells.csv`
- `map/karst_lithuania.geojson`
- `map/karst_latvia.geojson`
- `map/baltic_cities.geojson`
- `map/country_borders.geojson`
- `map/world.geojson`
- `map/elevation.geojson`
- `map/rivers.geojson`
- `map/karst_regions.geojson`

`manifest.csv` records the public source URLs. `checksums.sha256` is regenerated by `scripts/download_data.py`.

To populate these files after creating the GitHub repository, run the **Vendor public reproducibility data** GitHub Action once, or run locally:

```bash
python scripts/download_data.py --all
python scripts/verify_data.py
```

The large master ZIP is tracked with Git LFS. Before public redistribution, verify the upstream licensing/redistribution conditions for the underlying data products.
